### 6. 补充修复：随包可选壳停用后仍在「角色 → 界面壳」（用户 2026-11-15 反馈）

- 现象：内置里关掉「鲸歌可选壳」后，角色 → 界面壳 仍显示「鲸歌默认壳（Surface）」。
- 根因：`shellTargetsUi` 把 `builtin.shell.whale` 标成 `builtin=true`，而可见性规则
  「builtin 恒显示」本意只针对宿主内置实现（native 壳/内置存储等，`pluginId == null`）。
  whale 是带开关的 bundled 插件，不是宿主内置实现。
- 修复（`eedbb76`）：`visibleInRoleList()` 收紧为
  `(builtin && pluginId == null) || (enabled && permitted)`；RoleTargetUi / AgentTargetUi
  同规则；补单测（whale 停用隐藏、启用恢复、宿主内置实现停用时仍保留）。
- 真机：停 whale → 界面壳（3）且无「鲸歌默认壳」（`whale-off-role.xml`、`38-*.png`）；
  再启用 → 界面壳（4）恢复（`whale-on-role.xml`）。设备最后恢复为启用（原基线）。
